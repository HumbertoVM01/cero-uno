# Canon del Campo Social

1. Los comentarios son combustible social, no instrucciones literales.
2. La plataforma no obedece el campo: lo metaboliza.
3. Los comentarios agresivos no se publican crudos; se transforman en presión, estática, tensión o protección.
4. Las preguntas del colectivo alimentan la Home y el Archivo Vivo.
5. Los deseos del colectivo alimentan el Creador.
6. Las contradicciones del colectivo alimentan AEMP.
7. El Campo Social no registra Cero Unos ni usuarios; sólo describe presión de comparecencia.
8. Cada snapshot es temporal y puede cambiar en el siguiente ciclo.
