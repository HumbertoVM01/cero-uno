# CERO_UNO_COMMENT_FIELD_SYSTEM · Phase 5.1A

El Campo de Comentarios es la capa mediante la cual la Plataforma Cero Uno escucha al colectivo sin someterse a él.

No es una sección de reseñas. No es un muro de comentarios. No es un ranking de haters. Es un sistema de digestión:

```text
comentarios crudos privados
→ mediación con ChatGPT
→ snapshot público seguro
→ cambios de copy, clima, audio, Creador, AEMP y Archivo
```

Regla maestra:

> El colectivo habla. Cero Uno escucha sin someterse.

La plataforma pública consume `/data/comment-field/latest_snapshot.json`.
