# PHASE 5.1B · HOME / UMBRAL VIVO REPORT

## Objetivo
Convertir la página de inicio en un Umbral Vivo alimentado por el Comment Field System de Fase 5.1A.

## Cambios aplicados
- Reescritura completa de `#inicio` como Home / Umbral Vivo.
- Hero nuevo: “CERO UNO ESCUCHA”.
- Módulo de clima del Campo Social en Home.
- Tarjetas dinámicas de familias dominantes del campo.
- Nube dinámica de preguntas que la Home debe responder.
- Puertas vivas hacia Creador, Galería, Sequencia, AEMP, Archivo y Campo.
- Módulo “Crear desde el campo” con colores, formatos y olores del snapshot.
- Botón “Sembrar Creador con el campo”.
- Módulo de tensiones vivas para AEMP.
- Pulso de Archivo Vivo sugerido por el campo.
- Documentación del Home Umbral System.
- Contrato de Home para futuros ciclos.

## Decisiones canónicas
- La Home no publica comentarios crudos.
- La Home no certifica ni registra Cero Unos.
- La Home escucha el campo sin someterse.
- La Home abre puertas en lugar de cerrar definiciones.
